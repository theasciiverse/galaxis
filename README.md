# Galaxis

Find four lifeboats adrift in a starfield with probes that tell how many they can see, in as few tries as you can.

## Play

With [av](https://asciiverse.sh), the Asciiverse client:

```
av install galaxis
av play galaxis
```

Or download the archive for your system from this repository's Releases,
unpack it and run `./galaxis` (`galaxis.exe` on Windows).

## Credits

Eric S. Raymond's curses clone of Christian Franz's Macintosh freeware game,
begun in 1994 and still maintained (1.13, 2026). This build is his latest,
centred in the window, with two fixes: the mouse hint now shows, and a right
click or the scroll wheel no longer ends the game; it also builds for
Windows.
